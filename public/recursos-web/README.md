# Recursos web · IA para el Despacho

- `marca/`: logotipo AFCademIA a color y en negativo, símbolo y sello ENISA, todos PNG transparentes. El sello ENISA acredita a la empresa, no al curso.
- `iconos/`: 11 pictogramas SVG de trazo fino, navy, sin texto ni fondo. Se pueden usar en 32–80 px.
- `fondos/`: 3 fotografías WebP optimizadas para cabecera, sección editorial y matrícula, más 2 patrones SVG sutiles. Ninguna imagen incluye texto ni logos.
- `fondos/hero-despacho-continuo.webp`: versión anterior de cabecera en una sola escena. `hero-despacho-claro.webp` se conserva para comparar.
- `fondos/hero-malaga-puerto.webp`: cabecera activa con Málaga y el puerto al fondo. `hero-malaga-costa-alternativa.webp` es una segunda composición con más protagonismo del litoral. Ambas son imágenes generadas y funcionan como ambientación, no como fotografías documentales de la ciudad.

La fotografía de Roberto permanece solo en la sección del docente. La cabecera utiliza `public/hero-limpia.jpg`. El logo FUNDAE original permanece en `public/logo-fundae.png`; no se integra en estas nuevas piezas mientras no esté confirmada la bonificación del curso.
